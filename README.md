# 🤖 Mom Assistant Bot

Тёплый и заботливый Telegram-бот для мамы с поддержкой ИИ. Меню
организовано по категориям, каждое действие доступно и кнопкой, и
командой.

## 📁 Структура проекта

```
mom_bot/
├── main.py                 # точка входа: сборка Application, регистрация хендлеров, планировщик
├── config.py                # переменные окружения, часовой пояс, chat_id
├── content.py                # аффирмации, вопросы о настроении, пожелания, промпт для ИИ
├── colors_data.json          # календарь "цветов дня" (июнь–ноябрь 2026)
├── colors_repo.py            # загрузка colors_data.json, подбор цвета/месяца по дате
├── colors_image.py           # рендер картинки с цветовыми плашками
├── keyboards.py               # клавиатуры: главное меню + подменю категорий
├── services/
│   ├── ai_service.py          # OpenRouter: список моделей, запросы, история диалогов
│   ├── weather_service.py     # OpenWeather
│   └── instagram_service.py   # скачивание через yt-dlp
├── handlers/
│   ├── menu.py                 # /start, /help, переключение между категориями
│   ├── style.py                 # категория «Стиль дня»
│   ├── ai.py                    # категория «Помощник» (ИИ)
│   ├── weather.py               # категория «Погода»
│   ├── instagram.py             # категория «Медиа»
│   ├── broadcast.py             # плановые сообщения + пересылка ответов в канал
│   └── router.py                 # главный роутер входящих сообщений
├── fonts/                      # шрифты для генерации картинки цветов
├── requirements.txt
├── variables.example.txt       # шаблон переменных окружения (без реальных ключей!)
└── .gitignore                  # исключает variables.txt и .env
```

## 🎛 Категории меню

| Категория | Кнопки внутри | Команды |
|---|---|---|
| 🎨 Стиль дня | Цвета дня, Цвета на завтра, Аффирмация | `/colors`, `/colors_tomorrow`, `/affirmation` |
| 🧠 Помощник | Спросить ИИ, Очистить историю | `/ai`, `/clear` |
| 🌤 Погода | — (действие сразу) | `/weather` |
| 📥 Медиа | Скачать из Инсты | `/insta` |

Общие команды: `/start`, `/menu`, `/help`.

## 🚀 Быстрый старт

```bash
git clone <ссылка на твой новый репозиторий>
cd mom_bot

python -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate

pip install -r requirements.txt

cp variables.example.txt variables.txt
# впиши в variables.txt свои реальные TOKEN / ключи (см. ниже)

python main.py
```

## 📋 Переменные окружения

| Переменная | Описание | Пример |
|---|---|---|
| `TOKEN` | Telegram Bot Token | `123456789:ABC...` |
| `OPENROUTER_KEY` | API-ключ OpenRouter | `sk-or-v1-...` |
| `OPENWEATHER_KEY` | API-ключ OpenWeather | `c7da02ba...` |
| `CITY` | Город для погоды | `Rostov-na-Donu` |
| `MOM_CHAT_IDS` | Chat ID через запятую, кому шлём плановые сообщения | `549864131,8987266887` |
| `WATCH_USER_IDS` | Чьи ответы боту дублируются в канал | `549864131,8987266887` |
| `TARGET_CHANNEL_ID` | ID канала для пересылки | `-1004360677978` |

Все переменные — в `variables.txt` **локально** (файл в `.gitignore`,
никогда не коммить его). На хостинге задавай их через настоящие
переменные окружения — они всегда имеют приоритет над файлом.

## ⚠️ Важно про безопасность

1. **Никогда** не коммить `variables.txt` с реальными ключами.
2. Если ключ/токен когда-либо публиковался (в открытом репозитории,
   переписке, скриншоте) — считай его скомпрометированным и
   перевыпусти новый.
3. На проде используй переменные окружения хостинга, а не файл.

## 🧠 Система ИИ

- **API**: OpenRouter (бесплатные модели)
- Автопереключение между моделями при недоступности/лимите
- История последних 20 сообщений на пользователя (в памяти процесса —
  сбрасывается при перезапуске)

## 🔧 Как добавить новую кнопку/категорию

1. Добавь текст кнопки и, если нужно, новую категорию в `keyboards.py`.
2. Напиши хендлер в подходящем файле `handlers/` (или создай новый).
3. Зарегистрируй кнопку в `ACTION_ROUTES` или `CATEGORY_ROUTES` в
   `handlers/router.py`.
4. При желании добавь команду в `main.py` (`CommandHandler`).

## 📝 Логирование

Все события логируются с временной меткой: запуск бота, переключение
моделей ИИ, ошибки API, отправленные сообщения.
